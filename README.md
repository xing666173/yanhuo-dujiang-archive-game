# 雁火渡江：夏日回响

社会实践主题的 3D 情景互动游戏。当前版本包含序章和“芦苇深处的声音”第一章。

当前版本仅保留普通游戏入口，不提供教师浏览或章节直达界面。

## 操作方式

- 桌面端支持键盘和鼠标方向按钮移动。
- 按住并拖拽指针调整视角。
- 使用点击、E、Enter 或 Space 推进对话和互动。
- 粗指针设备使用屏幕摇杆移动和触摸区域调整视角。
- 自动画质会在性能不足时降档，也可在设置中手动选择画质。

## 协作实地任务

三个队友的热点各有一项短任务：陈屿负责“晨雾取景”，顾言负责“路线节奏”，林夏负责“安静收声”。每个热点都会按“简报 -> 互动任务 -> 结果对话 -> 章节评分”的顺序推进：先听清楚分工，再亲手完成任务，查看结果对话，最后把本项评价记入章节进度。

- **晨雾取景**：用鼠标移动或拖动取景准星，让取景准星跟随目标移动；也可以用 WASD 或方向键微调，手机上用触控拖动完成取景。
- **路线节奏**：观察横向路线上的游标，游标接近当前节点时点击行动按钮，或按键 E、Enter、Space；三个节点按顺序完成即可。
- **安静收声**：只在环境安静时按住录音按钮收声，也可以按住 E、Enter、Space 键；出现噪声就松开，等安静后再继续。

三项任务都支持鼠标、键盘和手机触控。任务没有一次失败就结束的惩罚：取消后可以重新尝试，刷新页面后也可以从保存的进度继续。每项任务按 1-3 星评定，总分仅保存在当前浏览器本地，不是教师评分；分数不上传、不联网，无排行榜。

## 本地预览

1. 安装 Node.js 依赖：`npm install`
2. 启动预览：`npm run preview`
3. 打开 `http://127.0.0.1:4173/`

## 测试

- 全部测试：`npm test`
- 仅逻辑与静态检查：`npm run test:unit`
- 仅浏览器流程：`npm run test:e2e`

## 发布

仓库根目录保持为可直接发布的 GitHub Pages 静态文件。所有运行时资源均保存在仓库本地。运行时资源全部使用相对路径，不依赖 CDN。
