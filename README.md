# 雁火渡江：夏日回响

社会实践主题的 3D 情景互动游戏。当前版本包含序章和“芦苇深处的声音”第一章。

当前版本仅保留普通游戏入口，不提供教师浏览或章节直达界面。

## 操作方式

- 桌面端支持键盘和鼠标方向按钮移动。
- 按住并拖拽指针调整视角。
- 使用点击、E、Enter 或 Space 推进对话和互动。
- 粗指针设备使用屏幕摇杆移动和触摸区域调整视角。
- 自动画质会在性能不足时降档，也可在设置中手动选择画质。

## 本地预览

1. 安装 Node.js 依赖：`npm install`
2. 启动预览：`npm run preview`
3. 打开 `http://127.0.0.1:4173/`

## 测试

- 全部测试：`npm test`
- 仅逻辑与静态检查：`npm run test:unit`
- 仅浏览器流程：`npm run test:e2e`

## 发布

仓库根目录保持为可直接发布的 GitHub Pages 静态文件。所有运行时资源均保存在仓库本地。运行时资源全部使用相对路径，不依赖 CDN。
